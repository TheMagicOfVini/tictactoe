    Method and data files

    Source: every Claude Code transcript under ~/.claude/projects/ for this project, including subagent transcripts. Each API call is one assistant message with a usage block. A streamed message is stored as several records with the same message id; those are merged, and the largest value of each usage field is kept.

    Calls whose stream never wrote a final usage record only carry the opening usage, where output is a handful of tokens. For those calls the output count is estimated from the generated content at about 3.6 characters per token, and the row is flagged output_estimated.

    Estimated cost uses list prices per million tokens: . Reported cost is the cost-state record Claude Code writes during a session; sessions that ended abruptly or are still running have none.

    Files next to this report: calls.csv (one row per API call), sessions.csv (one row per session), stats.json (all aggregates, including per-model and per-hour breakdowns).

    Column guide for calls.csv

    timestamp (UTC) · session_id · source (main or subagent) · model · effort · input_tokens (uncached) · cache_creation_tokens (split into cache_5m_tokens and cache_1h_tokens) · cache_read_tokens · output_tokens (best estimate) · output_tokens_recorded · output_estimated · thinking_tokens · context_tokens (input + cache write + cache read) · est_cost_usd · stop_reason · usage_final · tools (pipe separated) · text_chars · content_chars.
